## إعادة البناء من الصفر

```bash
cd survival_game
python3 tools/gen_terrain.py        # التضاريس + التخطيط + الخامات
python3 tools/gen_control.py        # خريطة التحكم
../godot/godot4 --headless --path . --import
../godot/godot4 --headless --path . --script tools/build_terrain.gd
../godot/godot4 --headless --path . --script tools/build_map.gd
../godot/godot4 --headless --path . --script tools/test_world.gd   # اختبار الخريطة
../godot/godot4 --headless --path . --script tools/test_player.gd  # اختبار الشخصية والحركة
```

## ملاحظات تنفيذية مهمة

- **⚠️ محرك الفيزياء:** `project.godot` يضبط `physics/3d/physics_engine="GodotPhysics3D"` — إلزامي! Jolt الافتراضي في Godot 4.5+ **لا يدعم VehicleWheel3D** (عجلات المركبات لا تعمل معه إطلاقاً).
- **تعليق العجلات:** `suspension_travel` يجب أن يكون كبيراً (≈1.1) — القوة = `stiffness × compression × mass` والانضغاط مقصور بالـ travel؛ بالقيمة الافتراضية 0.2 لا تستطيع العجلات حمل السيارة وتغوص في التضاريس.

- **دمج شخصيتك**: عدّل `data/character_default.tres` فقط (مسار النموذج + أسماء الأنيميشن + عظمة اليد) — انظر STAGE2_REPORT.md.
- **اللعب الجماعي**: فردي يعمل دائماً + وضع «استضافة/انضمام» عبر النقطة المحلية (LAN) كما طلبت.
- **موديل مضخة الوقود**: لا يوجد موديل CC0 جاهز لمضخة وقود في الحزم الموثوقة، فبُنيت مضخة مجمّعة من أشكال هندسية بسيطة بشكل واقعي (قاعدة، جسم أحمر، شاشة، خرطوش) — قابلة للاستبدال لاحقاً.
- **الكثافة**: تم ضبط الأشجار (9,146) للهواتف المتوسطة؛ يمكن رفعها في `data/layout.json` ثم إعادة `build_map.gd`.
- **التصدير APK**: تم! النتيجة `builds/survival_game.apk` (45.7MB، arm64، Android 7+، «حياة النجاة»). إعادة التصدير: `export JAVA_HOME=/home/user/jdk/jdk17 && export PATH=$JAVA_HOME/bin:$PATH && cd survival_game && /home/user/godot/godot4 --headless --path . --export-debug "Android" builds/survival_game.apk` — التفاصيل وإصلاح مسارات SDK في `STAGE6_REPORT.md`.
- **الوضع الشبكي (LAN)**: زر 📡 شبكة → استضافة/انضمام على نفس شبكة الواي فاي؛ صديق بالاسم، إطلاق نار ودهس، قاعدة دفع 1000، وقروض بموافقة الطرف الآخر — مُختبَر عبر عمليتين حقيقيتين.
